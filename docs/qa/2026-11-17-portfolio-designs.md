# 아키텍처·플로우 자료 검증

포트폴리오 홈과 설계 모음, 관련 사례 5곳에 공개 도식 11개를 연결했다. ALEX의 현재 코드 기반 구성·응답 흐름과 LION v2 설계 기여를 먼저 보여 준다.

- Aside에서 1440, 390, 360px 화면을 확인했다. 도식 11개가 모두 로드되고 페이지 가로 넘침이 없다.
- 확대, 전체 보기, 다시 확대, Esc, 닫기 버튼, 링크로 포커스 복귀를 확인했다. 모바일 닫기 버튼이 화면 안에 들어오는지도 검사했다.
- 홈에서 ALEX 설계로 이동하고, 사례 5곳의 이미지와 기존 회사 탭을 확인했다. 데스크톱과 모바일 화면을 직접 검수했다.
- HTML 14개 문서의 내부 링크와 앵커, 중복 ID를 검사했다. 기존 사례의 역할·성과·본문이 유지되는지도 대조했다.
- 도식의 PNG 메타데이터와 OCR, 새 편집 원본을 검사했다. 내부 IP·CIDR·접속 정보·키를 싣지 않았다. 기존 사내 배치도와 편집 파일은 Pages 산출물에서 제외한다.
- 공개 목록은 `content/designs.json`이며 배포 산출물에는 해당 PNG 11개만 포함된다. 기존 `assets/diagrams/` 폴더는 배포하지 않는다.
- `node --check site.js`, `git diff --check`, 공개 패키징과 CSS 색상 토큰 검사를 통과했다.

LION은 11월 v2 설계·리뷰 제안이다. 방향 전환과 구조 리뷰를 본인의 역할로, 설계 보드 작성과 구현은 담당 개발자의 역할로 구분했다. 출시 뒤 효과는 주장하지 않는다.
