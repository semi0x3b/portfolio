# 아키텍처·플로우 자료 검증

공개 도식 15개를 서비스 7개와 공통 인프라로 분류했다. XD Team의 서비스 구분에 맞춰 캠프파이어에 ALEX·LION, 부트캠프에 라이브룸·미래이력서를 배치했다.

- 변경 전 배포본에서 이미지 15개의 로딩은 성공했다. 카드 너비는 552px와 1,168px로 섞여 있었다. 사용자가 제보한 이미지 깨짐 자체는 재현하지 못했다.
- 변경 후 Aside에서 1440px·390px 화면을 직접 확인했다. 이미지 15개가 모두 디코딩되고 가로 넘침이 없다. 모든 미리보기는 PC에서 584×438px, 모바일에서 335×251.25px로 같은 4:3 비율이며 원본은 잘리지 않는다.
- PC·모바일에서 ALEX 이미지 클릭, 뷰어 표시, × 닫기, 클릭한 링크로 포커스 복귀를 확인했다. 뷰어에는 닫기 버튼 하나만 있다.
- 이미지의 날짜·출처 설명과 본문에 중복되던 소개 문장을 제거했다. 그림에는 제목·도식·범례를 두고, 기술 설명은 웹 본문에 적었다.
- 공개 HTML 14개의 내부 링크·앵커·중복 ID와 이미지 크기를 검사했다. 서비스 8개에 도식 15개가 중복 없이 연결되고, 육아휴직 문구와 이전 제작 시점 문구가 없다.
- 배포 파일의 이미지·스타일·스크립트 참조 96개에 내용 해시가 정확히 붙는지 확인했다. 원본 파일 경로와 외부 링크는 유지한다.
- 배포 PNG 15개의 파일 형식·크기를 공개 목록과 대조했다. `content/designs.json`에 등록한 이미지만 배포하며 편집 원본과 기존 `assets/diagrams/`는 제외한다.
- 공개 패키징, `node --check site.js`, `git diff --check`를 통과했다.

LION의 기여는 방향 전환 가이드, 서비스 책임 분리와 구조 설계 리뷰로 유지했다. 기존 경력의 재직 기간도 유지하고 육아휴직 설명만 공개 본문에서 제외했다.
