# 이력서와 회사별 상세 경력 확인

- 홈의 자기소개·경력 요약·경력기술서·포트폴리오 연결과 AI 활용 6개 항목을 확인했다.
- 경력 요약은 큰 프로젝트 단위로 작성했으며, 웹훅·HRD-Net·개별 장애 수정은 상세 프로젝트의 구현 내용에 포함했다.
- 네 회사의 상세 프로젝트 27개와 대표 사례 10개를 확인했다. 제이넷에서 자회사로의 소속 이전과 이전 직장 프로젝트를 보존했다.
- 회사 탭의 클릭·좌우 방향키·Home·End, 회사·프로젝트 직접 링크와 잘못된 해시의 기본 탭 처리를 확인했다.
- 1440·390·360px에서 가로 넘침과 자바스크립트 오류가 없었다. 390px에서는 회사 탭을 두 줄로 배치했다.
- 자바스크립트가 없거나 인쇄할 때도 네 회사의 내용이 모두 보이는지 확인했다.
- 게시 파일의 내부 링크·앵커를 대조하고 회사 비용 원금액과 내부 구성도 경로가 포함되지 않았는지 검사했다.
