# 서비스 목차·상세 화면 검증

서비스 선택은 `designs.html`에서, 아키텍처·세부 설계 열람은 `services/*.html`에서 한다. 서비스명 다음 요소는 대표 아키텍처이며 설명·관련 경험·세부 설계가 뒤따른다.

재현·검증 명령:

```sh
python3 tools/build-public.py
python3 tools/check-public.py
node --check site.js
git diff --check
```

브라우저에서는 PC 1440px·모바일 390px로 아래를 확인한다.

- 서비스 목차 8개에서 해당 상세로 이동하고 서비스 목차 링크로 돌아온다.
- 모든 상세의 첫 그림과 하단 설계가 로딩되고, 화면 가로 넘침이 없다.
- 그림 클릭·× 닫기·Esc·포커스 복귀와 원본 링크를 유지한다.
- 이전 `designs.html#서비스`·`#도식` 주소에서 같은 서비스·도식으로 이동한다. 알려지지 않은 앵커는 목차에 머무른다.
- 경력기술서 회사 탭의 클릭·방향키·직접 링크, 기존 프로젝트의 이미지 뷰어를 확인한다.

변경 전 공개 사이트의 구성도 15장을 뷰어로 열고 화면을 직접 확인했다. 이미지 누락·디코딩 실패는 재현되지 않았다. 기존 PNG 원본은 유지한다.

검증 결과: PC·모바일에서 서비스 8개의 이동·첫 그림·세부 설계·가로 넘침·뷰어 닫기·포커스 복귀를 통과했다. 기존 주소 31개가 같은 서비스·도식으로 이동한다. 회사 탭의 클릭·방향키·직접 링크와 기존 사례의 Esc 닫기·원본 이미지 링크도 확인했다.

홈의 설계 모음 카드가 ALEX PNG를 직접 여는 오류를 공개 브라우저에서 재현하고 서비스 목차로 수정했다. 공개 HTML 22개·참조 409개를 검사했고, 이 오류를 담은 임시 산출물에서는 검사기가 실패하는 것도 확인했다. 같은 데이터로 페이지를 다시 생성한 결과는 동일하다.
