김세미백엔드·인프라 엔지니어

백엔드에 강한 제너럴리스트

Python·FastAPI로 서비스를 만들고 Kubernetes·EKS·OKE에서 운영합니다. 요구사항의 선택지를 제안하며 개발을 리딩하고, AI와 자동화로 구현 범위와 팀의 작업 방식을 넓힙니다.

경력 요약 보기경력기술서 상세본

자기소개

Python과 FastAPI를 중심으로 백엔드를 개발합니다. SQLAlchemy, PostgreSQL, Redis로 데이터와 트랜잭션을 다루고, Kubernetes 기반의 AWS EKS와 OCI OKE를 Terraform과 ArgoCD로 구축·배포·운영합니다.

요구사항을 정하는 단계부터 빠진 정책과 예외를 짚고 선택지를 제안합니다. 백엔드와 인프라 경험을 바탕으로 구현 범위와 우선순위를 조율하며, 서비스 출시와 후속 개선까지 맡습니다.

반복되는 운영 업무는 어드민과 자동화로 옮기고, 성능·비용·장애 문제는 측정해서 개선합니다. 팀 리드로 개발 기준을 CI에 적용하고 운영 지식을 코드 옆에 남겨 팀이 함께 확인하고 고치도록 했습니다.

AI 활용 경험

  • 프론트엔드 구현: Claude Code로 필요한 Next.js 화면까지 구현합니다. 기존 코드와 요구사항을 함께 전달하고, 결과를 실제 화면과 API 동작으로 검증합니다.
  • 사내 업무 자동화: PR 본문 작성과 권한 등록, 배포·검증 등에 쓰는 사내 스킬과 운영 에이전트를 만들어 팀에 배포했습니다.
  • 팀 도입과 공유: Claude Code의 Agent Skills와 Plugin System을 사내 세미나에서 발표하고, 직군별 활용 예시와 사용 가이드를 공유했습니다.
  • 학습 서비스 개발: OpenAI API와 pgvector로 수업 STT 인덱서, RAG 학습 튜터와 요약노트를 개발해 강의 데이터를 복습에 활용했습니다.
  • 생성 결과 검수: AI 이력서의 품질 기준을 코드 검사와 LLM 판정으로 나누고, 모델·프롬프트 비교와 오염 입력 시험으로 결과를 확인했습니다.
  • 장애 분석: 규칙이 먼저 신호를 찾고 LLM이 해석하도록 구성했습니다. 인용 근거는 원본 로그와 대조하고, 분석 봇에는 운영 변경 권한을 주지 않았습니다.
