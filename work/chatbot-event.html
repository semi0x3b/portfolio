문제

;

브랜드 필름 온에어(11월 7일)에 맞춰 필름 속 캐릭터의 말투로 대화하는 챗봇 이벤트를 4주 안에 열어야 했습니다.

한 일

;
  • 대화는 로그인 없이 열고, 추첨권을 받는 순간에만 로그인을 요구해서 참여 문턱을 낮췄습니다.
  • API 6종과 테이블, Redis 키, 스케줄 잡, 알림톡 템플릿 6종까지 작업 범위를 문서 하나로 묶고 데이터 구조를 정했습니다.
  • 메시지마다 응답 상태(정상, 오류, 한도 초과, 시간 초과)와 OpenAI 요청 ID를 남겨서 장애를 바로 추적할 수 있게 했습니다.

결과

;
  • 이벤트 기간 챗봇 참여는 45,253건으로 목표 6,000건의 7.5배였고 장애는 없었습니다.
  • 캠페인 전후로 부트캠프 지원 완료가 593명에서 1,057명으로 늘었습니다.
